## 问题清单与修复方案

### 问题 1: notifications 集合 created/updated 字段为空

#### 问题描述
创建通知记录时，`created` 和 `updated` 字段为空，导致前端无法显示通知创建时间。

#### 根因分析
- `notifications` 集合的 `created` 和 `updated` 是普通 date 字段，不是系统字段
- PocketBase 不会自动填充普通字段的时间戳
- `init-pb-collections.js` 中使用了错误的 `systemFields` 配置方式

#### 修复方案
在创建通知时手动设置时间戳：

**修改文件**: `src/stores/matchmaking.ts`

```typescript
// 创建邀请通知
const now = new Date().toISOString()
await pb.collection('notifications').create({
  sender_id: matchmakerId,
  user_id: user.id,
  notification_type: 0,
  related_id: application.id,
  content: inviteContent,
  is_read: false,
  created: now,      // 新增
  updated: now       // 新增
})
```

**修改位置**:
- 创建邀请通知 (第 245 行)
- 创建接受通知 (第 379 行)
- 创建拒绝通知 (第 437 行)
- 标记已读更新 (第 454 行)

### 问题 2: 创建会话和群组时权限不足 (403 错误)

#### 问题描述
双方接受邀请后，系统尝试创建 `communication_sessions`、`chat_groups`、`chat_group_members` 记录时返回 403 Forbidden 错误。

#### 根因分析
- `communication_sessions`、`chat_groups`、`chat_group_members` 的 `createRule` 设置为 `null`
- `createRule: null` 表示只有超级管理员才能创建记录
- 普通用户（红娘和被邀请人）没有创建权限

#### 修复方案
将 `createRule` 修改为 `@request.auth.id != ""`，允许已认证用户创建记录。

**修改文件**: `scripts/init-pb-collections.js`

```javascript
// 修改前
createRule: null,

// 修改后
createRule: '@request.auth.id != ""',
```

**受影响集合**:
| 集合名 | 原权限 | 新权限 |
|--------|--------|--------|
| `communication_sessions` | null (仅超级管理员) | `@request.auth.id != ""` |
| `chat_groups` | null (仅超级管理员) | `@request.auth.id != ""` |
| `chat_group_members` | null (仅超级管理员) | `@request.auth.id != ""` |

**补丁脚本**: `scripts/patch-collection-rules.js`

#### 修复状态
✅ 已完成

### 问题 3: number 字段配置错误 (onlyIntegers vs onlyInt)

#### 问题描述
创建 chat_group 时返回验证错误: `Cannot be blank`，尽管已传递了 `group_type: 0`。

#### 根因分析
1. **属性名错误**: `init-pb-collections.js` 中使用了 `onlyIntegers` 属性，但 PocketBase 实际应为 `onlyInt`
2. **0 值被视为空**: PocketBase 将 number 类型字段的 `0` 值视为空值（blank），导致验证失败

#### 修复方案
1. 将 `onlyIntegers` 改为 `onlyInt`
2. 将枚举值从 1 开始（0 被视为空值）

**修改文件**: `scripts/init-pb-collections.js`

```javascript
// 修改前
{ type: 'number', name: 'group_type', min: 0, max: 1, onlyIntegers: true }

// 修改后
{ type: 'number', name: 'group_type', min: 1, max: 2, onlyInt: true }
```

**枚举值变更**:
| 字段 | 修改前 | 修改后 |
|------|--------|--------|
| `group_type` | 0=大群, 1=小群 | 1=大群, 2=小群 |
| `member_role` | 0=普通成员, 1=群主 | 1=普通成员, 2=群主 |
| `is_active` | 0=不活跃, 1=活跃 | 1=活跃, 2=不活跃 |

**代码变更**:
- `src/stores/matchmaking.ts`: 更新 `group_type`、`member_role`、`is_active` 值
- `src/stores/chat.ts`: 更新 `relationTag` 检查条件

**补丁脚本**: `scripts/patch-number-fields.js`, `scripts/patch-field-minmax.js`

#### 修复状态
✅ 已完成
